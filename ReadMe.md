
# NumPy Student Performance Analyzer

A beginner-friendly Python project that analyzes student academic performance using NumPy.

## Project Overview

This project analyzes student marks across multiple subjects and generates a performance report using NumPy arrays and mathematical operations.

## Features

- Calculate total marks for each student.
- Calculate average marks and percentages.
- Identify the overall class topper.
- Find subject-wise toppers.
- Count passed and failed students.
- Classify students based on their average marks.
- Calculate the overall class average.
- Generate a class performance summary.

## Technologies Used

- Python
- NumPy

## Dataset

The project contains 5 students and 3 subjects:

- Maths
- Science
- History

## Installation

1. Download or clone this repository.
2. Install NumPy:

   ```bash
   python -m pip install numpy
   ```

3. Run the program:

   ```bash
   python main.py
   ```

## Learning Objectives

- Understand NumPy arrays and 2D arrays.
- Perform array operations using axis.
- Use NumPy statistical functions such as `sum()`, `mean()`, `max()`, and `argmax()`.
- Apply loops and conditional statements to analyze data.
